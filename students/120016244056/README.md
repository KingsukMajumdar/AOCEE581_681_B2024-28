# Submission Guide

Place your work in a subfolder matching the module, using this naming pattern:

    Module_01/<roll_no>_M01_<descriptor>.<ext>
    Module_02/<roll_no>_M02_<descriptor>.<ext>
    Module_03/<roll_no>_M03_<descriptor>.<ext>
    Module_04/<roll_no>_M04_<descriptor>.<ext>
    Module_05/<roll_no>_M05_<descriptor>.<ext>
    MiniProject/<roll_no>_MP_<descriptor>.<ext>

descriptor examples: code, report, dataset, plot

You do not need to create the Module folder yourself beforehand,
just place your file at that path and git will create it.
